# Sound Deck (웹 앱)

혼자 쓰는 단계용 영단어 웹 앱. 사파리에서 열고 "홈 화면에 추가"로 설치한다.

## 파일
- `index.html`, `app.js`: 화면과 학습 규칙
- `sounds.js`: 소리 카드 37개(모음 20, 자음 17), 입 모양 애니메이션 (영어 소리 지도에서 가져와 호주식 모음 추가)
- `words-a.js`: 기본 단어 625개 (`tools/build_words.py`로 생성)
- `sw.js`, `manifest.webmanifest`, `icon-*.png`: 홈 화면 앱, 오프라인
- `apps-script/Code.gs`: "Don't know" 목록을 구글 시트에 백업

## 학습 규칙 (명세서 13, 15절)
- 2026-11-23(월)부터 하루 50개, 번호 순서. 하루는 새벽 4시에 바뀐다.
- 복습: 배운 날 + 1, 3, 7, 14, 30, 60일. 카드별 기록은 저장하지 않는다.
- Don't know를 누른 단어만 그날 날짜를 저장하고, 그날 세트 끝에 다시 나오며, 그날부터 복습을 새로 시작한다.
- 새 단어에 처음 나오는 소리는 그 단어 바로 앞에 소리 카드로 먼저 나온다. 새 소리는 하루 최대 8개.
- 14일차(2026-12-06)부터 기본 확장(626~3000위) 30개 + 분야 단어 20개.
- 미리 보기: 주소 뒤에 `?day=3`을 붙이면 3일차를 저장 없이 볼 수 있다.

## 단어 목록
SUBTLEX-US 기본형 순위 1~642위에서 욕설, 감탄사(uh, um, huh 등), 이름(jack, sam), 중복을 뺀 625개.
발음은 호주 표준 발음(General Australian). CMUdict(미국식)를 규칙으로 호주식으로 바꾼다: 모음 뒤 r 안 읽음, 모음 20개(iː ɪ e æ ɐ ɐː ɔ ʊ ʉː ɜː ə oː æɪ ɑe oɪ æɔ əʉ ɪə eː ʊə), after·last 같은 단어는 ɐː, news·student는 j 넣음, 모음 사이 t는 ɾ. 단어 음성은 아이폰 호주 음성(en-AU). 그림은 아직 이모지(127개)뿐이고, 나머지는 소리 듣고 말하기 카드.

## 설치
1. GitHub 저장소 Settings → Pages → Branch `main` / root 저장.
2. 아이폰 사파리에서 `https://<계정>.github.io/<저장소>/` 열기 → 공유 → 홈 화면에 추가.

## 구글 시트 백업
1. 새 구글 시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용 붙여넣기.
2. 배포 → 새 배포 → 유형 "웹 앱", 실행 계정 "나", 액세스 "모든 사용자" → 배포.
3. 나온 `…/exec` 주소를 앱 ⚙︎ 설정에 붙여넣기 → Sync now.
주소를 아는 사람은 이 시트에 쓸 수 있으니 주소는 공유하지 않는다.
